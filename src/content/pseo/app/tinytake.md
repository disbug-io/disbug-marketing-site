TinyTake is an easy-to-use screen capture tool that lets you record videos, create image files and annotate them with comments. It's perfect for creating quick tutorials or to use as a bookmarking tool to save pages for later.

You can select the type of screen capture you want, whether the whole screen or a particular region. You can also annotate the screenshots and the videos with textbox, arrow, hightlight etc. You can share you file online or get a shareable link instantly. You can also view your history with Tinytake.

#### Pros:

- Free cloud storage is provided
- Simple and intuitive user interface
