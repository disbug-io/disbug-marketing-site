### What is UAT?

UAT (User Acceptance Testing) is a process that helps to ensure the quality of a software before it is released to the public. It involves running tests on the software with real users in order to identify any issues and correct them before the software is made available to the public.

There are different types of UAT, including:

#### System testing

This type of UAT tests the functionality of the software by running it on a simulated environment.

#### User testing

This type of UAT involves using real users to test how the software behaves under various conditions.

#### Mobile testing

This type of UAT tests how well the software performs on mobile devices.

### User Acceptance Testing Process

The user acceptance testing process typically involves the following steps:

#### 1\. Planning and preparation

During this stage, you'll need to decide which tests you want to run and how many users you'll need for each test. You'll also need to prepare any software or hardware needed for the tests.

#### 2\. Testing

Once you've decided on your test plan, it's time to get started! In general, user acceptance

testing involves using real users to test how the software behaves under various conditions.

#### 3\. Evaluation and feedback

After the tests are complete, it's important to evaluate the results and provide feedback to your team. This will help you identify any issues that need to be fixed before the software is made available to the public.

There are a number of different types of user acceptance testing that you can use to evaluate your software.

**Traditional User Acceptance Testing (TUT)** is the most common type of UAT. TUT involves using real users to test how the software behaves in a simulated environment. This allows you to identify and fix any errors before they cause problems for actual users.

**Functional User Acceptance Testing (FUT)** is another type of UAT. FUT involves using real users to test how the software performs in a simulated environment while also testing how it behaves under various conditions. This allows you to find and fix any issues that may cause problems for users during actual use.

**Structured User Acceptance Testing (SUT)** is another type of UAT that uses specific steps and protocols to test how the software behaves. SUT helps you identify any errors before they cause problems for users.
