### What is Userback?

Userback is a web based platform for feedback collection, bug tracking and sharing that provides a solution for website owners, developers, and agencies to collect user feedback from web projects and share information about them with colleagues.

### Userback Pricing

**Solo $14/mo 2 members (additional member for $4.5/member)** This plan includes: - 1 project - Unlimited reporters - Feedback fidget - Browser extension - Video feedback - Team collaboration - Notifications

**Startup $59/mo 10members (additional member for $4.5/member)** This plan includes: Everything in Solo, plus: - 5 projects - Unlimited reporters - Session replay - Workflow customization - Project access - Integrations

**Deluxe $119/mo 15members (additional member for $4.5/member)** This plan includes: Everything in Startup, plus: - 25 projects - Unlimited reporters - Developer tools - Javascript API - User identification - Branding - Export data

### Is Userback worth the price?

There is no definitive answer to this question as it depends on what you are looking for in a bug tracking application. If you are mainly interested in the features offered by Userback which is specific to bug reporting, you can go for it. But there are other tools out there with better features at much lesser price.
